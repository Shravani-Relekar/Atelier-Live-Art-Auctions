1 · High-Level Design

System context & components
Reads go REST → route → Prisma → serializer (hides reserve price & password hash). Writes (bids) run in one SERIALIZABLE transaction holding a row lock on the lot; events are broadcast only after commit.
Real time: Socket.io rooms per lot, per auction and per user. One client-side bridge patches every TanStack Query cache entry containing the lot; stale events are dropped by version.
Images go browser → Cloudinary directly with a server-issued signature; the API verifies the asset before attaching it. The database is the single source of truth; sockets are only a notification channel.
